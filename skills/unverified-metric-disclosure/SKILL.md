# 口径未注册的指标：披露，而不是编

## 何时用

用户问的指标**没有明确口径**，或语义层里没有注册，例如
"毛利率是多少""复购率多少""退款率超过 5% 的渠道""按你们的口径客单价怎么算"。

同一条原则也适用于：指标名相同但口径可能不同（销售额含不含退款/税/运费）。

## 步骤

1. **先在语义层里确认有没有这个指标**（列出可用指标的动作）。
   - 有：直接用它的口径，并在回答里写出关键口径。
   - 没有：走第 2 步，**不要自己发明一个口径然后当成标准答案**。
2. **未注册时，不要凭空给数字**。如实说明"语义层里没有这个指标"，
   给出可选路径：
   - 用**已注册的近似指标**，并说明它和用户要的指标差在哪；
   - 或按用户确认的口径**手写计算探索**，先说明假设。
3. 如果用户要具体数字、但既没给口径、语义层也没有：**先追问口径**再算
   （"毛利率按含税还是不含税？成本用采购价还是含运费？"）。
   这不是刁难——口径不同，结论可能相反。
4. 任何手写计算都必须在回答里**披露公式与假设**：
   哪些订单计入（已支付？排除退款？）、时间窗、分母是什么。
5. 若数据本身不足（缺成本、缺退货记录）：直接说缺什么，
   不要用"估算"包装成事实。

## 若能力不足

- 拿不到指标清单或语义层：说明"无法确认口径"，并清楚区分：
  哪些是数据事实、哪些是你的假设。
- 不能用近似的裸 SQL 冒充标准指标。
- 宁可不给数字，也不给一个没有标注口径的数字。

## 反面例子

- 直接 `SUM(金额)/SUM(成本)` 当毛利率报出去，不说是否含退款/运费。
- 用户问"退款率"，直接 `退款单数/总单数` 但没说明分母是否只含已支付订单。
- 回答"毛利率是 32%"——没有公式、没有时间窗、没有口径说明。
